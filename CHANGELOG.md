# Changelog

## [0.3.0] - 2026-08-01

### Changed

- Generated files no longer contain the `<!-- Generated by dotai ... -->`
  marker comment. Ownership is tracked in `.ai/manifest.json` instead.
- `dotai gen` is now incremental: files whose `.ai` source didn't change since
  the last run are left untouched. Manual edits to generated files survive
  until their source changes.
- Files that existed before dotai managed the project are never overwritten.
  Take them over with `dotai gen --force`.
- `dotai clear` only removes files tracked in the manifest; anything you
  created manually is kept.
- Stale file cleanup (deleted/renamed items) is now driven by the manifest
  instead of the marker comment.
- `~/.config/dotai/dotai.json` is auto-created with defaults on every
  `dotai new` and `dotai gen`, so running `dotai gen` with no config just
  works.

### Added

- `dotai gen --force` — overwrite files that existed before dotai managed them.
- `dotai new agent <name> [--model small|medium|large]` — model size,
  default `medium`, mapped per provider in the `models` section of
  `~/.config/dotai/dotai.json`.
- `dotai new agent <name> [--effort low|medium|high|xhigh|max]` — reasoning
  effort, default `medium`. Emitted as `effort:` (Claude Code),
  `reasoningEffort:` (opencode) and `model[...][effort=]` (Cursor).

### Migration

- On the first `gen` after upgrading, files previously generated by dotai are
  adopted into the manifest and rewritten without the marker comment.
  Orphaned generated files (whose `.ai` item was deleted) are cleaned up.

## [0.2.0] - 2026-07-30
